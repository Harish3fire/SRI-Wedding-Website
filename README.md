# Srividhya & Diwakar Wedding Invitation

Complete updated project.

## Run
1. npm install
2. npm run dev

## Edit wedding content
Edit `src/main.jsx`, starting at the `WEDDING` object near the top.

## Assets
- Background music: `public/audio/wedding.mp3`
- Wedding video: `public/video/wedding.mp4`
- Images: `public/images/`

## Current behavior
- Four editable event cards: Groom Welcoming, Engagement, Wedding Ceremony, Reception.
- Countdown ends at 30 October 2026, 8:00 AM IST and triggers fireworks.
- Wedding video pauses the background music while playing and resumes it when paused or ended, if music was playing before the video.
